# 미니 노션 (PWA)

노션처럼 블록으로 메모를 쓰는 웹앱입니다. 아이폰과 안드로이드 모두 홈 화면에 설치할 수 있고, 설치 후에는 인터넷 없이도 열립니다.

## 기능
- **페이지**: 추가·삭제, 이모지 아이콘, 끌어서 순서 바꾸기(폰은 길게 누른 뒤 끌기), 제목·내용 검색
- **블록**: 문단, 제목 1·2·3, 글머리 목록, 번호 목록, 체크리스트, 토글, 인용, 코드, 구분선, 이미지, 파일
- **입력**: `/` 메뉴, 마크다운 단축키(`#` `##` `###` `-` `1.` `[]` `>` + 공백, ```` ``` ````, `---`)
- **글자 꾸미기**: 글자를 선택하면 굵게·기울임·밑줄·취소선 막대 (Ctrl+B / I / U, Ctrl+Shift+X)
- **블록 옮기기**: 왼쪽 ⋮⋮ 손잡이를 끌기, Alt+↑/↓. 손잡이를 누르면 위로·아래로·복제·다운로드·삭제 메뉴
- **첨부파일**: `/이미지`, `/파일`, 화면에 끌어다 놓기, 이미지 붙여넣기. 파일은 브라우저 IndexedDB에 저장
- **이미지 다루기**: 양쪽 가장자리 막대를 끌어 크기 바꾸기, 이미지 위 버튼으로 원래 크기·다운로드·삭제
- **지우기**: 이미지·파일·구분선을 눌러 선택하고 Delete(또는 Backspace). 글 끝에서 Delete를 누르면 다음 블록을 이어 붙임
- **되돌리기**: Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y), 위쪽 ↶ ↷ 버튼
- **백업**: 왼쪽 아래 '백업 내보내기'로 첨부파일까지 JSON 한 파일로 저장, '백업 가져오기'로 복원
- **화면 테마**: 위쪽 버튼으로 자동 → 밝게 → 어둡게

## 파일
| 파일 | 역할 |
| --- | --- |
| index.html | 화면 뼈대, manifest·아이폰 meta 태그, 서비스 워커 등록 |
| style.css | 디자인 |
| app.js | 기능 (페이지, 블록 편집기, / 메뉴, 첨부파일, 되돌리기, 백업, localStorage·IndexedDB 저장) |
| manifest.json | 앱 이름, 아이콘, 전체 화면(standalone), 테마 색 |
| service-worker.js | 앱 파일을 저장해 두고 오프라인에서도 열리게 함 |
| icons/ | 192px, 512px, 아이폰용 180px 아이콘 |

## 설치 방법
1. GitHub Pages 등 **https 주소**에 올립니다. (http나 같은 Wi-Fi IP 주소에서는 설치가 되지 않습니다)
2. 안드로이드 Chrome: 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가
3. 아이폰 Safari: 공유 버튼 → 홈 화면에 추가

## 고친 뒤 반영하기
service-worker.js의 `CACHE` 이름 숫자를 올리고(v1 → v2) 다시 올리면, 폰에서 앱을 두 번 정도 다시 열 때 새 버전으로 바뀝니다.

## 알아둘 점
- 데이터는 기기마다 따로 저장됩니다 (PC와 폰, Safari와 홈 화면 앱도 서로 따로). 다른 기기로 옮길 때는 백업 내보내기 → 가져오기를 쓰세요.
- 브라우저 사이트 데이터를 지우면 메모와 첨부파일도 지워집니다. 중요한 내용은 가끔 백업해 두세요.
